## 📖 Deskripsi
Repositori ini berisi dokumentasi lengkap, file simulasi (`.pkt`), dan laporan teknis dari serangkaian proyek Uji Kompetensi (Ujikom) perancangan arsitektur jaringan komputer menggunakan **Cisco Packet Tracer**. Proyek ini mendemonstrasikan kemampuan mulai dari konfigurasi perangkat *router/switch* dasar, penerapan protokol *routing* dinamis, integrasi layanan server penuh, hingga manajemen keamanan dan *backup-restore* sistem jaringan[cite: 5, 6, 7].

---

## 📁 Daftar Studi Kasus & Dokumentasi Proyek

### 1️⃣ Case 1: Konfigurasi Dasar, Addressing, & DHCP
- **Deskripsi:** Membangun topologi jaringan awal[cite: 6], konfigurasi IP Address pada antarmuka *router*[cite: 6], serta pengaturan DHCP Server untuk distribusi alamat IP dinamis ke perangkat klien[cite: 6] (LAN1 & LAN2[cite: 6]).
- **Dokumentasi & File:** Tersedia di folder [`Case-1/`](./Case-1) (mencakup file simulasi dan laporan PDF[cite: 6]).

### 2️⃣ Case 2: Routing Dinamis OSPF & Multi-Router
- **Deskripsi:** Menghubungkan topologi *multi-router* menggunakan protokol *dynamic routing* **OSPF** (Open Shortest Path First)[cite: 5] untuk memastikan seluruh subnet jaringan dapat saling berkomunikasi secara efisien dan otomatis.
- **Dokumentasi & File:** Tersedia di folder [`Case-2/`](./Case-2) (mencakup file simulasi dan laporan PDF[cite: 5]).

### 3️⃣ Case 3: Integrasi Server, Keamanan, & Backup-Restore (Final Project)
- **Deskripsi:** Implementasi dan pengujian layanan tingkat lanjut meliputi **DNS Server**[cite: 7], **Web Server** (HTTP)[cite: 7], **Email Server** (SMTP/POP3)[cite: 7], dan **FTP Server**[cite: 7]. Dilengkapi pula dengan penerapan aturan *Firewall* (Access Control List/ACL) serta praktik pengujian *backup and restore running-config* router melalui koneksi FTP.
- **Dokumentasi & File:** Tersedia di folder [`Case-3/`](./Case-3) (mencakup file simulasi dan laporan PDF lengkap[cite: 7]).
